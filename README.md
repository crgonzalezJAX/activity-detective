# Activity Detective

Activity Detective is an interactive exhibit for exploring smartphone motion data. The notebooks summarize the UCI HAR dataset, train a baseline and neural network activity classifier, and export examples and metrics for a browser game that lets visitors compare their guesses with the model.

Data: [UCI Human Activity Recognition Using Smartphones](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones) (Anguita et al., 2013), CC BY 4.0.

## Reproduce

1. Create and activate a Python virtual environment.
2. Run `pip install -r requirements.txt`.
3. Download the UCI HAR dataset and place it at `data/UCI HAR Dataset/`.
4. Run `notebooks/01_explore.ipynb`, then `notebooks/02_model.ipynb`.
